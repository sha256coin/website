What's new in v3.0.1: the mandatory upgrade for the merged-mining (AuxPoW) hard fork at block 17,500. If you already upgraded to 3.0.0, you must upgrade again. Merge-mining proofs now use Namecoin's exact format, so Namecoin-style pool software works unchanged, and the merge-mining chain ID is 598. Nodes older than 3.0.1 will split off at the first merge-mined block. No reindex is needed. Pool operators, see the pool integration notes. Full details in the release notes.
